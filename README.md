# GUZAL — kosmetologiya sayti

## Ishga tushirish

Eng oson usul: `START-SITE.bat` faylini ikki marta bosing. U local Vite serverni ishga tushirib, saytni Chrome’da ochadi.

Terminal orqali:

```bash
npm install
npm run dev
```

Keyin brauzerda `http://127.0.0.1:5173/` manzilini oching.

`index.html` faylini bevosita Chrome’da ochmang — React/Vite module fayllari local `file:///` rejimida ishlamaydi.
